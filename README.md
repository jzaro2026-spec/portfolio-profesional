# Portfolio profesional

## Ejecutar en local

**Requisito:** Node.js 24.12 o posterior.

1. Instala las dependencias con `npm install`.
2. Inicia el servidor con `npm run dev`.
3. Abre <http://127.0.0.1:3000>.

La conexión opcional con Gmail requiere que Firebase y Google OAuth tengan
configurado `localhost` como dominio autorizado. El resto del portfolio funciona
sin credenciales adicionales.
